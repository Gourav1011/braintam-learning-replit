====================================================
IMPORTANT INSTRUCTIONS
======================

This is a LIVE production project.

DO NOT BREAK:

* Authentication
* Clerk integration
* Existing users
* Existing payments
* Razorpay webhooks
* Existing APIs
* Existing dashboards
* Existing database records
* Existing student records

Before making any change:

1. Read the entire codebase.
2. Understand existing architecture.
3. Reuse existing components.
4. Reuse existing patterns.
5. Do not create duplicate functionality.
6. Extend existing modules whenever possible.
