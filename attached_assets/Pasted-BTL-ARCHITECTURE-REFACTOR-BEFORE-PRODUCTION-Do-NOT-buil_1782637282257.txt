1. MASTERY COURSES
   ==================================================

2. IGNITE MENTORS
=================

Ignite is the sales/demo pipeline.

Create an "Ignite Mentors" tab under Ignite.

Expected menu:

Ignite
├── Dashboard
├── Leads
├── Demo Batches
├── Sales Mentors
├── Ignite Mentors
├── Attendance Analytics
├── Conversion Center
├── Payments
└── Reports

Ignite Mentors screen should manage demo students only.

Actions:

✓ Assign students/leads
✓ Reassign students/leads
✓ Edit mentor
✓ Disable mentor
✓ View assigned students
✓ View mentor performance
✓ Move student to Mastery

There should NOT be any "Move to Sales" option.

If these features already exist elsewhere, consolidate them into one screen.
