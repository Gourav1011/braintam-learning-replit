# BTL CRM – Sales Mentor (SSM) Final Workflow Design

## Objective

Sales Mentor (SSM) is responsible for:

* Ignite 6-Day Program students
* Daily follow-ups
* Parent communication
* Attendance monitoring
* Homework monitoring
* Conversion tracking
* Retention support

This is NOT a traditional sales CRM.

This is a Student Success + Conversion Management system.

---

# MENTOR TYPE

Do NOT create a separate portal.

Keep existing mentor portal architecture.

Add:

mentor_type

Values:

academic
sales_ssm

Both use same login system.

Render different menus and dashboards based on mentor_type.

---

# GOAL

The Sales Mentor dashboard should function as a daily action queue.

Mentors should spend time calling, following up, supporting parents, and converting students—not managing CRM columns.

The system should automatically organize leads and follow-ups while preserving complete communication history.
