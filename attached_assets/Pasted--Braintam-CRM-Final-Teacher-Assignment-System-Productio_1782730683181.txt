# Core Principle

Permission Source = Assignment

Grade = Academic Information Only

Grades organize students and curriculum.

Grades must NEVER determine teacher access.

---

# Source of Truth

Always use:

teacher_id

Display only:

teacher_name
teacher_email

Never use teacher_name for permissions because names can:

* Change
* Be duplicated
* Have different spellings
* Be edited by admins

IDs never change.

---

# Final Visibility Rules

## My Sessions

Show session if:

session.teacher_id = teacher.id

Fallback:

session.teacher_name = teacher.name

Fallback should remain temporarily only for old data migration.

Goal:

100% teacher_id-based.

---

## My Batches

Show batch if:

batch.primary_teacher_id = teacher.id

OR

EXISTS (
SELECT 1
FROM demo_sessions
WHERE
demo_sessions.batch_id = batch.id
AND demo_sessions.teacher_id = teacher.id
)

This is important because:

A batch can have:

Math Teacher
Science Teacher
English Teacher
Substitute Teacher

One batch can have multiple teachers.

---

## My Live Classes

Show live class if:

live_class.teacher_id = teacher.id

OR

live_class.session_id belongs to teacher

OR

live_class.batch_id belongs to teacher

---

# Remove Single-Teacher Assumption

Current:

batch.teacher_id

Recommended:

batch.primary_teacher_id

Reason:

A batch can have:

Primary Teacher
Assistant Teacher
Substitute Teacher
Demo Teacher
Special Workshop Teacher

Do not assume only one teacher exists per batch.
