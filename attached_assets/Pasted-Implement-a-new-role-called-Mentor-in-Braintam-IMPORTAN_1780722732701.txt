Implement a new role called "Mentor" in Braintam.

IMPORTANT:

This is NOT a Teacher role.

This is NOT an Admin role.

Mentors are Student Success Managers whose job is to monitor student engagement, attendance, homework completion, academic consistency, and parent follow-ups.

The Mentor Portal must be lightweight, fast, and focused only on student success and retention.

=================================================
NEW USER ROLE
=============

Add new role:

mentor

Existing roles:

* admin
* teacher
* mentor
* student

Future:

* parent

=================================================
ADMIN PANEL CHANGES
===================

Create:

Admin → Mentors

Admin should be able to:

* Create Mentor
* Edit Mentor
* Disable Mentor
* Reset Mentor Password
* Assign Students
* Reassign Students

Admin can assign:

1 Student → 1 Mentor

A mentor can manage multiple students.
