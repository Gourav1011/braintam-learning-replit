# BRAINTAM STUDENT PORTAL — COMPLETE UI REDESIGN

## PRIMARY OBJECTIVE

Redesign the existing Braintam student portal into a simple, child-friendly learning experience for Grade 1–5 students.

The existing portal currently has too many independent sidebar options:

- Dashboard
- Live Classes
- Courses
- Recordings
- Animated Videos
- Homework
- Assignments
- Tests
- Leaderboard

Replace this with only five primary navigation destinations:

1. Home
2. Classes
3. Learn
4. Tasks
5. Rewards

The Space Journey must become Braintam's main visual attraction. It should contain lightweight, premium animations without reducing performance.

---

# CRITICAL IMPLEMENTATION RULES

Before modifying code:

1. Inspect the existing student portal routes.
2. Inspect all current student components.
3. Inspect current API hooks and query functions.
4. Inspect the existing sidebar.
5. Inspect current live-class data.
6. Inspect course, subject and lesson relationships.
7. Inspect homework, assignment and test APIs.
8. Inspect XP, rank, leaderboard and achievement logic.
9. Reuse existing components where practical.
10. Preserve all backend functionality.

DO NOT:

- Create a separate static demo.
- Create duplicate student pages.
- create duplicate database tables.
- Delete existing APIs.
- Replace real data with hardcoded mock data.
- hardcode student names.
- hardcode grades.
- hardcode subjects.
- hardcode XP.
- hardcode rank.
- hardcode teacher names.
- hardcode class information.
- change teacher or admin portals.
- modify existing business logic unless required to fix an identified bug.
- award XP from frontend code.
- install Three.js.
- install a heavy particle library.
- use large autoplay animations.

The frontend must display data from the existing APIs.

If an API value is missing, use a safe empty state instead of fake data.

## Current level calculation

If not already returned by the API:

```tsx
export function getCurrentJourneyLevel(
  xp: number,
  levels: typeof journeyLevels
) {
  return (
    [...levels]
      .reverse()
      .find((level) => xp >= level.minXP) ||
    levels[0]
  );
}
```

Progress calculation:

```tsx
export function getJourneyProgress(
  xp: number,
  level: {
    minXP: number;
    maxXP: number | null;
  }
) {
  if (level.maxXP === null) {
    return 100;
  }

  const earnedInLevel =
    Math.max(0, xp - level.minXP);

  const levelRange =
    level.maxXP - level.minXP;

  return Math.min(
    100,
    Math.max(
      0,
      (earnedInLevel / levelRange) * 100
    )
  );
}
```

## Star field

Use one fixed star layer.

Maximum:

```text
25–35 stars
```

Do not render hundreds of elements.

Generate stable stars once:

```tsx
import {
  useMemo
} from "react";

export function useJourneyStars(
  count = 30
) {
  return useMemo(
    () =>
      Array.from(
        {
          length: count
        },
        (_, index) => ({
          id: index,
          left:
            `${Math.random() * 100}%`,
          top:
            `${Math.random() * 100}%`,
          size:
            `${1 + Math.random() * 2}px`,
          delay:
            `${Math.random() * 4}s`,
          duration:
            `${3 + Math.random() * 4}s`
        })
      ),
    [count]
  );
}
```

Render:

```tsx
<div
  className="journey-stars"
  aria-hidden="true"
>
  {stars.map((star) => (
    <span
      key={star.id}
      className="journey-star"
      style={{
        left: star.left,
        top: star.top,
        width: star.size,
        height: star.size,
        animationDelay: star.delay,
        animationDuration:
          star.duration
      }}
    />
  ))}
</div>
```

- total XP

# ACCESSIBILITY

All interactive elements must:

- be keyboard accessible;
- have visible focus states;
- use semantic buttons and links;
- have accessible names;
- meet reasonable colour contrast;
- avoid flashing;
- support reduced motion.

Minimum touch target:

```css
min-width: 42px;
min-height: 42px;
```

Images require useful alt text.

Decorative stars and planets must use:

```tsx
aria-hidden="true"
```
