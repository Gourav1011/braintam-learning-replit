ADMIN PANEL REQUIREMENTS & LMS FLOW UPDATES

1. ANALYTICS MODULE

* Add filters/options:

  * Grade selection
  * Academic Year selection
  * Batch selection

Overview section should include:

* Class-wise analytics
* User-type filter

  * Student
  * Teacher
  * Admin
* Grade-wise analytics
* Search option

2. COURSES MODULE

* Add Edit Course option
* Course should represent purchased program/batch
* Course fields:

  * Course Name
  * Grade
  * Academic Year (mandatory)
  * Batch
  * Course Description
  * Banner/Thumbnail

REMOVE:

* Single subject dependency

Because:

* One course may contain multiple subjects
* Admin can manually select subjects inside course

FLOW:
Course
→ Subject
→ Chapter
→ Topic
→ Content

Before selecting Chapter:

* Subject selection should be compulsory

3. TOPIC & ID SYSTEM

* Homework should be topic-wise
* Tests should be topic-wise
* Live classes should be topic-wise
* Assignments should be topic-wise

Current issue:
Topic IDs are globally sequential:
1,2,3,4...

Required:
Every course should have unique 4-digit topic IDs.

Example:
CBSE Grade 5:
5001
5002

NEET Foundation:
7001
7002

Topic IDs should be generated course-wise.
