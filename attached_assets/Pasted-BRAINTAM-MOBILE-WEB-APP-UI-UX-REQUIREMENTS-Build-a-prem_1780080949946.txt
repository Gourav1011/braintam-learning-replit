BRAINTAM MOBILE WEB APP UI/UX REQUIREMENTS

Build a premium, modern, mobile-first EdTech web application for Braintam inspired by ODA Class's user flow and engagement, but using Braintam's existing brand identity and colors from braintam.com.

The application should feel like a native Android app while running as a Progressive Web App (PWA).

Design Philosophy

Create a premium educational platform that combines:

ODA Class's engagement and gamification
Clean Apple-style layouts
Modern SaaS dashboard design
Parent trust and professionalism

The UI must be minimal, modern, highly responsive, and visually appealing for both students and parents.
