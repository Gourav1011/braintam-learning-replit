Braintam LMS - Complete Academic Structure + Teacher Portal Integration

IMPORTANT ARCHITECTURE

The system must have separate Admin Portal and Teacher Portal.

ADMIN PORTAL controls the academic structure.

TEACHER PORTAL uses the academic structure created by Admin.

Teachers must NOT be allowed to create or edit:

* Courses
* Subjects
* Chapters
* Topics

Only Admin can create and manage academic content.

IMPORTANT DEVELOPMENT RULES

1. Teachers cannot create Courses, Subjects, Chapters or Topics.

2. Admin controls academic structure.

3. All Homework, Tests, Assignments, Notes and Live Classes must be linked to an existing Topic.

4. When Teacher selects:

Course → Subject → Chapter → Topic

all created content must automatically be stored under that Topic.

5. Use search and dependent dropdowns.

6. Avoid huge dropdown lists.

7. Build scalable database architecture for future growth.

8. Keep UI modern, simple and similar to leading EdTech platforms.

9. System must support future growth to thousands of topics, classes, homework records and test attempts.

10. This architecture must be fully integrated with existing Course Management, Teacher Portal and Student Portal.
