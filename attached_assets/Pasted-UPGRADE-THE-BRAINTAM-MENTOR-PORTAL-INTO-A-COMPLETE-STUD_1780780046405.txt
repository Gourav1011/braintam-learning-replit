UPGRADE THE BRAINTAM MENTOR PORTAL INTO A COMPLETE STUDENT SUCCESS CRM

IMPORTANT:
Do not create unnecessary complexity.
Keep the UI clean, fast, professional and scalable for 10,000+ students.
Follow CRM principles similar to Zoho CRM, HubSpot and modern Student Success platforms.

====================================================

1. PERMANENT STUDENT TIMELINE (HIGHEST PRIORITY)
   ====================================================

Create a permanent student timeline.

Rules:

* Notes can NEVER be deleted.
* Notes can only be added.
* Edits must create audit history.
* Timeline remains attached to the student forever.
* If mentor changes, all previous notes remain visible.
* Admin, Mentor and Teacher can view the timeline.
* Timeline must show:

Date & Time
Created By
Role
Note Type
Remark
Follow-Up Date
Action Taken

Example:

06 Jun 2026
Mentor Priya
Parent Call
Parent concerned about attendance.

08 Jun 2026
Teacher Rahul
Homework Reminder Sent.

10 Jun 2026
Admin Gourav
Converted Demo to Paid Student.

2. FOLLOW-UP REMINDER SYSTEM
============================

When mentor enters a Next Follow-Up Date:

Automatically create a reminder.

Reminder Status:

* Due Today
* Upcoming
* Overdue
* Completed

Create separate menu:

REMINDERS

Dashboard widgets:

* Due Today
* Overdue
* Next 7 Days
* Completed

Rules:

* Reminder cannot disappear.
* Completed reminders remain in history.
* When completing reminder, mentor must enter remarks.
* If new follow-up date entered, next reminder automatically created.

Escalation Rules:

1 Day Overdue:
Show orange warning.

3 Days Overdue:
Show red warning.

7 Days Overdue:
Notify Admin.

15 Days Overdue:
Flag mentor performance.
