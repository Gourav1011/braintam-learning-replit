5. TEACHER AUTO-INHERIT
=======================

When creating a new batch:

Check previous batch:

SELECT teacher_id
FROM demo_batches
WHERE course_id = :courseId
ORDER BY start_date DESC
LIMIT 1;

If teacher exists:

Copy teacher_id into:

new batch
all sessions
all live classes

Fallback order:

Session Teacher
↓
Batch Teacher
↓
Course Default Teacher
