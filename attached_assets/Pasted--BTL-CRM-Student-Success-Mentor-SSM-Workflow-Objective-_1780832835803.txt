# BTL CRM – Student Success Mentor (SSM) Workflow

## Objective

Convert the current Mentor module into a Student Success Mentor (SSM) system that manages:

* Ignite 6-Day Program leads
* Daily follow-ups
* Attendance tracking
* Homework tracking
* Parent communication
* Conversion tracking
* Long-term retention

Mentors do NOT manually create leads.

Leads are assigned by Admin through Ignite batches.

---

# ADMIN FLOW

## Lead Assignment

Existing lead assignment system remains.

Admin creates:

* Ignite G1
* Ignite G2
* Ignite G3

Example:

G1 = 50 Leads
G2 = 50 Leads

Admin assigns:

Mentor A → G1 + G2
Mentor B → G3

All students of those groups automatically become assigned to that mentor.

No manual lead assignment by mentor.
