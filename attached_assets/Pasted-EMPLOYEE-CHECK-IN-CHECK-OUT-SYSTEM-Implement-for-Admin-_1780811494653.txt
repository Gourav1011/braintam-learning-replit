EMPLOYEE CHECK-IN / CHECK-OUT SYSTEM

Implement for:

* Admin
* Teacher
* Sales Mentor
* Academic Mentor

====================================================

1. DAILY CHECK-IN
   ====================================================

When user logs in for the first time each day:

Show:

CHECK IN

Capture:

* Date
* Time
* User
* Role
* Device
* Browser
* IP Address (optional)

Status:

Checked In

====================================================
2. DAILY CHECK-OUT
==================

Create:

CHECK OUT

Before checkout show:

Today's Summary

Auto-fill:

For Teachers:

* Classes Conducted
* Students Attended
* Homework Assigned
* Tests Conducted

For Sales Mentors:

* Calls Made
* Follow-Ups Completed
* Leads Contacted
* Conversions

For Academic Mentors:

* Students Contacted
* Follow-Ups Completed
* Doubt Sessions Conducted
* Parent Calls

User enters:

* Work Summary
* Challenges
* Pending Tasks
* Tomorrow Priorities

Click:

Submit & Check Out
