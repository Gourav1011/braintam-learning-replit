Redesign it.

* Remove fixed grade assignment cards.
* Use a scalable assignment system.
* Create a "Manage Grades" modal.

  * Grade 1
  * Grade 2
  * …

  * Checkbox selection
  * Select All

* One mentor can handle multiple grades.
* Show lead count beside each mentor.
* Show workload percentage.
* Show overload warning if mentor exceeds limit.
