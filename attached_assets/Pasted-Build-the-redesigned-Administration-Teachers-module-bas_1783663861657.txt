==================================================
TEACHER ASSIGNMENT RULE
==================================================

Teachers are NOT permanently grade-specific.

Grades are only teaching capabilities.

A teacher may teach:

- Multiple grades
- Multiple subjects
- Multiple courses
- Ignite courses
- Mastery courses
- Individual live classes

Assignment hierarchy:

Program
→ Course
→ Subject
→ Teacher

Programs:

Ignite
Mastery

Assignment types:

1. Default Subject Teacher

Example:

Teacher:
Priya Sharma

Program:
Mastery

Course:
Grade 6 Mastery 2026–27

Subject:
Mathematics

Result:

Priya becomes the default Mathematics teacher only for that selected course.

When a new Mathematics live class is created for this course, automatically preselect Priya.

Admin may override the teacher.

2. Individual Class Teacher

Assign a teacher only to one selected live class.

Do not modify the default Subject Teacher.

3. Substitute Teacher

Assign a temporary teacher for:

- One class
- Selected classes
- Date range

Store:

originalTeacherId
substituteTeacherId
startDate
endDate
reason
assignedBy
createdAt
