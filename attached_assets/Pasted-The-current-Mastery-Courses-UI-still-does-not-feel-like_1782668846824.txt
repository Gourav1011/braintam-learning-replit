The current Mastery Courses UI still does not feel like a premium CRM.

Problems:

1. Statistic cards are too large.
2. Icons are oversized and consume unnecessary space.
3. Too much empty whitespace.
4. Information density is low.
5. Course cards are too tall and require excessive scrolling.
6. Large banners/images waste screen space.
7. Important actions are hidden below the fold.
8. The page should show significantly more information without feeling crowded.
9. On page load, there is a "Failed to Load" error. Investigate and fix the API error, loading states, and any failing requests.

PERFORMANCE FIXES
=================

Investigate the "Failed to Load" issue.

Check:

* Which API request is failing
* Network response
* Console errors
* Infinite re-renders
* Missing loading states
* Missing query parameters
* Undefined data causing crashes

Requirements:

* Skeleton loaders
* Empty states
* Error boundaries
* Retry button
* No blank page
* No console errors
* No refresh loops
